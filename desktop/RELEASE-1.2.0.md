# Markdown Studio for Windows — v1.2.0

의존성 없는 단일 파일 마크다운 에디터의 Windows 데스크탑 빌드입니다.
이번 릴리스는 **1.1.1** 이후의 신규 기능과 수정을 포함합니다.
1.1.1과 달리 이 빌드는 **코드 서명이 되어 있습니다**(자체서명 — 아래 ‘설치 시 참고’ 확인).

## ✨ 새로운 기능

### 뷰어에서 찾기
- 읽기전용(뷰어)으로 연 문서에서도 **앱 안 찾기**가 됩니다. 상태바의 **찾기** 버튼 또는 **Ctrl+F** 로 엽니다.
- 미리보기에 그려진 글자를 그대로 검색해 강조하고, **이전/다음(Enter · Shift+Enter)**, **대소문자 구분**, **일치 개수** 표시, 해당 위치로 **자동 스크롤**을 지원합니다.
- 편집 모드에서는 기존처럼 찾기·바꾸기가 모두 동작하고, 뷰어에서는 바꾸기 UI는 자동으로 숨겨집니다.

### 탭 순서 바꾸기
- 상단 문서 탭을 **끌어서 순서를 바꿀 수 있습니다.** 놓을 위치가 세로선으로 표시됩니다.

### 문서가 지정한 서식(CSS) 적용
- 문서 안에 쓴 `<style>` 블록과 `style="…"` 속성이 이제 **미리보기·뷰어·인쇄·HTML/PDF 내보내기에 그대로 반영**됩니다. 글꼴 색, 정렬, 배경, 표 서식 등을 문서마다 다르게 줄 수 있습니다.
- 안전을 위해 걸러내는 것들이 있습니다. 바깥 리소스를 불러오는 값(`url()`, `@import`)과 앱 화면을 덮을 수 있는 `position` 계열은 제외되며, 문서가 지정한 선택자는 **본문 영역 안으로만** 적용됩니다. 즉 문서가 사이드바나 상태바의 모양을 바꿀 수는 없습니다.
- Word(.docx) 내보내기는 CSS를 쓰지 않으므로 서식 지정이 반영되지 않습니다(본문만 나갑니다).

### 편집 모드 양방향 스크롤
- 지금까지는 편집기를 굴려야 미리보기가 따라왔습니다. 이제 **미리보기를 굴리면 편집기도 같은 위치로 따라옵니다.**
- 긴 문서에서 결과를 보며 고칠 곳을 찾은 뒤 바로 그 자리를 편집할 수 있습니다.

### 링크·이미지 문법 확장
표준 마크다운에서 흔히 쓰지만 그동안 동작하지 않던 표기들을 지원합니다.

| 표기 | 예 |
|---|---|
| 제목(툴팁) | `[네이버](https://naver.com "검색")` |
| 주소 속 괄호 | `[위키](https://ko.wikipedia.org/wiki/한국_(나라))` |
| 공백이 든 경로 | `[문서](<내 문서.md>)` · `![사진](<내 사진.png>)` |
| 참조식 | 본문에 `[보이는 글자][ref]`, 아무 곳에나 `[ref]: https://example.com` |
| 꺾쇠 자동 링크 | `<https://example.com>` · `<name@example.com>` |
| 대괄호 낀 텍스트 | `[문서 [초안]](https://example.com)` |

- 참조식 정의 줄은 화면에 나오지 않으며, 코드 블록 안에 쓴 것은 정의로 취급하지 않습니다.
- 앱 안 **문법 가이드(Ctrl+/)** 3장에 위 내용이 추가되었습니다.

### 상대경로 이미지
- 문서와 같은 폴더에 있는 그림을 `![](사진.png)` · `![](이미지/도표.png)` 처럼 **경로만 적어 바로 쓸 수 있습니다.** 별도의 폴더 선택 과정이 필요 없습니다.
- 문서를 연 위치를 기준으로 찾으므로 **열기 · 새로 만들기(저장 후) · 탐색기에서 더블클릭** 모두 동일하게 동작합니다.
- 인쇄 미리보기와 HTML/PDF/Word 내보내기에도 반영됩니다.

## 🛠 개선 및 버그 수정

- **탐색기에서 `.md` 를 더블클릭해 연 문서**를 편집 모드로 바꾼 뒤 저장하면 ‘다른 이름으로 저장’ 창이 뜨던 문제를 고쳤습니다. 이제 **원본 파일을 그 자리에 덮어씁니다.**
- 앱의 **열기**로 연 파일도 저장 시 쓰기 권한을 받지 못해 덮어쓰기가 되지 않던 문제를 함께 고쳤습니다.
- `<https://example.com>` 처럼 꺾쇠로 감싼 주소가 **잘못된 주소로 링크되던** 문제를 고쳤습니다.
- 주소에 밑줄이나 별표가 들어간 링크(`…/a__b__c`)가 굵게·기울임으로 잘못 해석되던 문제를 고쳤습니다.
- 창이 비활성 상태였을 때 **스크롤 동기화가 멈춘 채 돌아오지 않던** 문제를 고쳤습니다.
- 렌더 직후 곧바로 내보내면 **상대경로 이미지가 빠진 채** 저장되던 문제를 고쳤습니다.
- 같은 파일을 여러 번 열었을 때 **최근 파일 목록에 중복**으로 쌓이던 문제를 고쳤습니다.

## ⚠️ 설치 시 참고 (자체서명 코드 서명)

이 빌드는 **자체서명(self-signed) 인증서로 코드 서명**되어 있습니다. 공인 CA 인증서가 아니므로, PC의 보안 설정에 따라 아직 경고가 뜨거나 차단될 수 있습니다.

- 서명 주체: `CN=Samsung Asset Management Co., O=Samsung Asset Management Co., C=KR`
- 지문(SHA1): `718938EF7B57EFF69679635E805F0BE62D06019A` · 유효기간 2031-08-28

**설치가 막힐 때**

- **SmartScreen** 파란 창 "Windows가 PC를 보호했습니다"가 뜨면 → **[추가 정보] → [실행]**.
  (또는 파일 우클릭 → 속성 → 하단 **‘차단 해제’** 체크 → 확인 후 실행.)
- **Smart App Control(SAC)** 이 "이 앱을 차단했습니다"라고 하며 실행 버튼이 없는 경우 → **자체서명으로는 통과하지 못합니다.** SAC는 사용자가 신뢰 등록한 루트를 인정하지 않고, 공인 CA 서명이나 마이크로소프트 평판만 통과시킵니다. 이때는 다음 중 하나를 택합니다.
  - SAC가 꺼진 PC에서 설치한다(SAC는 한번 끄면 다시 켤 수 없고, 이미 켜진 PC에서 끄는 것은 Windows 재설치 전까지 되돌릴 수 없습니다).
  - **포터블 빌드**를 사용한다 — 원본 실행 파일 바이트를 그대로 쓰므로 SAC를 통과합니다.
  - 공인 OV/EV 코드 서명 인증서로 다시 서명한다(근본 해결).

**인증서를 신뢰 등록해 경고를 없애려면** (SAC가 꺼진 PC)

`desktop/codesign/mds-selfsign.cer` 를 대상 PC의 **신뢰할 수 있는 루트 인증 기관** 과 **신뢰할 수 있는 게시자** 에 등록하면 서명이 ‘유효함’으로 표시되고 SmartScreen 경고가 사라집니다. 등록 전에는 `Get-AuthenticodeSignature` 결과가 `UnknownError`(루트가 신뢰되지 않음)로 나오는 것이 정상입니다.
