# Markdown Studio for Windows — v1.1.1

의존성 없는 단일 파일 마크다운 에디터의 Windows 데스크탑 빌드입니다.
이번 릴리스는 마지막 배포판 **1.0.0** 이후의 신규 기능과 개선을 모두 포함합니다.
(1.1.0은 내부 검증 단계에서만 만들어졌고 외부 배포되지 않았습니다. 그때 발견된 문제는 1.1.1에서 수정되었습니다.)

## ✨ 새로운 기능

### 이미지 삽입 (문서에 내장)
- 사이드바 **이미지** 버튼, **붙여넣기(Ctrl+V)**, **드래그 앤 드롭**으로 그림을 넣을 수 있습니다.
- 이미지는 문서 안에 **base64로 내장**되어, 파일 하나로 완결됩니다 — 뷰어·인쇄·HTML/PDF/Word 내보내기에서 별도 폴더 없이 그대로 보입니다.
- 큰 이미지(최장변 1600px 초과 또는 1.5MB 초과)는 **자동 축소**되어 문서 용량이 과도하게 커지지 않습니다. GIF 애니메이션 등은 원본이 유지됩니다.

### mermaid 다이어그램
- ` ```mermaid ` 코드 블록을 **다이어그램(SVG)으로 렌더**합니다. 플로차트·시퀀스·간트 등.
- 미리보기·뷰어·인쇄·HTML/PDF 내보내기에 모두 반영됩니다(오프라인 동작).

### 인쇄 미리보기
- 인쇄(Ctrl+P) 시 **앱 안에서 실제 인쇄 레이아웃(페이퍼)을 먼저 미리보기**로 확인한 뒤 인쇄/‘PDF로 저장’을 진행합니다.

### 뷰어 우선 열기
- **열기(Ctrl+O)** 는 기본적으로 **뷰어(읽기전용) 모드**로 엽니다. 편집이 필요하면 **Ctrl+E** 또는 상태바에서 편집 모드로 전환합니다.
- 실수로 원본을 수정하는 일이 줄어듭니다.

### 내보내기에 문서 정보(프론트매터) 포함
- 문서 상단의 `--- … ---` 메타데이터(제목·작성자 등)가 이제 **HTML·PDF·Word 내보내기에도 표로 함께** 출력됩니다.

## 🛠 개선 및 버그 수정
- **코드 블록 복사 버튼**이 정상 동작하도록 수정했습니다.
- 타이핑 직후 곧바로 내보내기/인쇄해도 **최신 내용이 누락되지 않도록** 수정했습니다.
- 큰 문서·이미지 문서에서 **입력 반응성 개선**(미리보기 렌더 최적화).
- 이미지 삽입 위치·동일 다이어그램 중복 표시·대용량 이미지 처리 메모리 등 세부 안정화.

## 📦 배포물
- `MarkdownStudio-Setup-1.1.1.exe` — NSIS 설치 프로그램
- `MarkdownStudio-portable/` — 폴더형 포터블(설치 불필요, 폴더 안 `Markdown Studio.exe` 실행)

## 💻 시스템 요구사항
- Windows 10 / 11 (64비트)
- 별도 런타임 설치 불필요(필요 구성 요소가 함께 배포됩니다).

## ⚠️ 설치 시 참고 (코드 서명 없음)
이 빌드는 **코드 서명이 되어 있지 않습니다.** 그래서 Windows 보안 기능이 설치를 막을 수 있습니다.

- **SmartScreen** 파란 창 "Windows가 PC를 보호했습니다"가 뜨면 → **[추가 정보] → [실행]** 으로 진행합니다.
  (또는 파일 우클릭 → 속성 → 하단 **‘차단 해제’** 체크 → 확인 후 실행.)
- **Smart App Control(SAC)** 이 "이 앱을 차단했습니다"라고 하며 실행 버튼이 없으면 → SAC는 개별 우회가 없습니다. 이 경우:
  - 회사 코드 서명 인증서로 **서명된 설치본**을 사용하거나,
  - **포터블 빌드**(`MarkdownStudio-portable/`)를 사용하세요. 포터블은 원본 실행 파일을 그대로 사용해 SAC를 통과합니다.

> 근본 해결책은 신뢰된 인증서로 **코드 서명**하는 것입니다. 서명하면 SmartScreen·SAC 모두 통과하며 설치 프로그램을 그대로 쓸 수 있습니다.
