# Markdown Studio for Android — v1.2.0

의존성 없는 단일 파일 마크다운 에디터의 안드로이드 빌드입니다.
Play 게시본 **1.1.1(versionCode 3)** 이후의 신규 기능과 수정을 담았습니다.
운영 키스토어(`mds-prod`)로 서명된 `app-release.aab`(versionCode 4)를 업로드합니다.

## ✨ 새로운 기능

### 문서 내부 링크(앵커)
- 제목(헤딩)에 자동으로 id가 붙어, `[가는 곳](#제목)` 형태의 **문서 안 이동 링크**가 동작합니다.
- 미리보기·뷰어에서 그 링크를 누르면 해당 제목 위치로 스크롤됩니다.
- id 규칙: 소문자화, 문장부호 제거, 공백은 `-`로. 같은 제목이 여러 번이면 두 번째부터 `-1`, `-2`가 붙습니다(한글 제목도 지원). 예) `## 2. 설치` → `#2-설치`.
- HTML로 내보낸 문서에서도 앵커가 그대로 남아 브라우저에서 클릭 이동이 됩니다.

### 뷰어에서 찾기
- 읽기전용(뷰어)으로 연 문서에서도 **앱 안 찾기**가 됩니다. 상태바의 **찾기** 버튼으로 엽니다.
- 미리보기에 그려진 글자를 검색해 강조하고, 이전/다음 이동, 대소문자 구분, 일치 개수 표시, 해당 위치 자동 스크롤을 지원합니다.
- 편집 모드에서는 찾기·바꾸기가 모두 동작하고, 뷰어에서는 바꾸기 UI가 자동으로 숨겨집니다.

### 탭 순서 바꾸기
- 상단 문서 탭을 **끌어서 순서를 바꿀 수 있습니다.** 놓을 위치가 세로선으로 표시됩니다.

### 문서가 지정한 서식(CSS) 적용
- 문서 안에 쓴 `<style>` 블록과 `style="…"` 속성이 **미리보기·뷰어·HTML 내보내기에 그대로 반영**됩니다. 글꼴 색, 정렬, 배경, 표 서식 등을 문서마다 다르게 줄 수 있습니다.
- 안전을 위해 바깥 리소스를 불러오는 값(`url()`, `@import`)과 앱 화면을 덮을 수 있는 `position` 계열은 제외되며, 문서가 지정한 선택자는 **본문 영역 안으로만** 적용됩니다.

### 편집 모드 양방향 스크롤
- 편집기를 굴리면 미리보기가, **미리보기를 굴리면 편집기도** 같은 위치로 따라옵니다.

### 링크·이미지 문법 확장
표준 마크다운에서 흔히 쓰지만 그동안 동작하지 않던 표기들을 지원합니다.

| 표기 | 예 |
|---|---|
| 제목(툴팁) | `[네이버](https://naver.com "검색")` |
| 주소 속 괄호 | `[위키](https://ko.wikipedia.org/wiki/한국_(나라))` |
| 공백이 든 경로 | `[문서](<내 문서.md>)` |
| 참조식 | 본문에 `[보이는 글자][ref]`, 아무 곳에나 `[ref]: https://example.com` |
| 꺾쇠 자동 링크 | `<https://example.com>` · `<name@example.com>` |
| 대괄호 낀 텍스트 | `[문서 [초안]](https://example.com)` |

- 참조식 정의 줄은 화면에 나오지 않으며, 코드 블록 안에 쓴 것은 정의로 취급하지 않습니다.
- 앱 안 **문법 가이드** 3장에 위 내용이 추가되었습니다.

## 🛠 버그 수정
- `<https://example.com>` 처럼 꺾쇠로 감싼 주소가 **잘못된 주소로 링크되던** 문제를 고쳤습니다.
- 주소에 밑줄이나 별표가 들어간 링크(`…/a__b__c`)가 굵게·기울임으로 잘못 해석되던 문제를 고쳤습니다.
- 화면이 비활성 상태였다가 돌아왔을 때 **스크롤 동기화가 멈춰 있던** 문제를 고쳤습니다.
- 렌더 직후 곧바로 내보내면 **이미지가 빠진 채** 저장되던 문제를 고쳤습니다.
- 같은 파일을 여러 번 열었을 때 **최근 파일 목록에 중복**으로 쌓이던 문제를 고쳤습니다.

## 📦 배포물
- `app-release.aab` — Play Console 업로드용 App Bundle (versionCode 4, 운영 키 `mds-prod` 서명)
- `app-release.apk` — 사이드로드·직접 배포용 (동일 서명)
- 산출물 경로: `android-app/android/app/build/outputs/`

## 📱 안드로이드 참고
- **PDF 내보내기:** 안드로이드 WebView에는 인쇄 대화상자가 없어 직접 PDF 저장은 되지 않습니다. **HTML로 내보낸 뒤 공유 시트의 ‘인쇄 / PDF로 저장’**을 이용하세요.
- **상대경로 이미지**(`![](사진.png)`)는 문서가 있는 폴더를 기준으로 찾는 기능으로, **데스크톱 전용**입니다. 안드로이드에서는 이미지를 문서에 삽입(내장)해 사용하세요.
- `.md` 파일 열기·공유 인텐트, 네이티브 저장·공유는 기존과 동일하게 동작합니다.

## 🏪 Play Console ‘새로운 기능’ (붙여넣기용)

한국어:
```
- 문서 내부 링크(앵커): [가는 곳](#제목) 로 문서 안 이동
- 뷰어에서도 찾기 지원
- 문서 탭 끌어서 순서 바꾸기
- 문서가 지정한 서식(CSS) 반영
- 편집 모드 양방향 스크롤
- 링크·이미지 문법 확장 및 관련 버그 수정
```

English:
```
- In-document anchor links: jump within a doc via [go](#heading)
- Find works in the read-only viewer too
- Drag document tabs to reorder
- Document-supplied CSS (<style> / style="…") is applied
- Two-way scroll sync in edit mode
- Extended link/image syntax and related fixes
```
