## Full description  (max 4000)

```
Markdown Studio is a fast, private, fully offline Markdown editor. Write on the left, see a live preview on the right, and export a polished document when you're done — no account, no ads, no tracking.

WRITE AND PREVIEW
• Real-time side-by-side preview as you type
• Clean, distraction-free "paper" theme
• Line numbers, word/character count, and adjustable editor width
• Optional word wrap and adjustable preview font

EVERYTHING MARKDOWN
• Headings, bold/italic/strikethrough, links and images
• Ordered, unordered, and checkbox task lists
• Blockquotes (including nested), tables, and horizontal rules
• Front-matter metadata rendered as a tidy info card
• Fenced code blocks with syntax highlighting for Python, JavaScript, TypeScript, JSON, SQL, Bash, HTML, and CSS — pick the language per block and copy code with one tap

WORK WITH MULTIPLE DOCUMENTS
• Tabbed editing for several documents at once
• Recent documents list to jump back in quickly
• Read-only viewer mode for distraction-free reading
• Built-in syntax guide to learn Markdown by example
• Customize the template used for every new document

OPEN AND SHARE
• Open .md, .markdown, and .txt files
• Open Markdown files shared from other apps
• Save and share your work through the Android share sheet

EXPORT
• Export to Markdown (.md), a self-contained HTML file, or Word (.docx)
• Print / save as PDF via the system print dialog

PRIVATE BY DESIGN
• 100% offline — your writing never leaves your device
• No account, no analytics, no advertising, no tracking
• Nothing is uploaded to the developer

Markdown Studio keeps it simple: a fast editor that respects your privacy and gets out of your way.
```
